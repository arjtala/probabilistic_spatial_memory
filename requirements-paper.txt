# requirements-paper.txt — minimal pin set for the PSM paper reproduction bundle.
#
# Scope: regenerate the submitted fixed-budget/HDD figures, aggregate tables,
# and paired statistics from reader-generated JSON captures via
# `bash scripts/reproduce_paper.sh`. Raw datasets and captures do not ship in
# this repository. No GPU or API key is needed once captures exist. Tested
# against Python 3.12.13.
#
# Install:
#   python -m pip install -r requirements-paper.txt
#
# The full extraction-side dependency tree (torch, transformers,
# projectaria-tools, ffmpeg, etc.) lives in extraction/pyproject.toml
# and is only needed to regenerate the captures themselves.
