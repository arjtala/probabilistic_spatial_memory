\begin{abstract}
An agent on wearable glasses must remember its environment without its
memory growing unboundedly with recording time. We propose
\textbf{Probabilistic Spatial Memory} (\psm), a streaming spatial-temporal
index whose state is budgeted by the physical \emph{area} explored, not the
\emph{length} of the recording---$O(\text{area})$, not $O(\text{time})$.
Concretely, \psm{} partitions the wearer's trajectory into fixed geographic
cells (an H3 hex grid), so state is capped per place rather than per frame.
Each cell keeps a reservoir-sampled set of embedding exemplars for retrieval
and a time-decayed HyperLogLog sketch that counts distinct events across
revisits; a single knob (\caponek{}) trades spatial coverage for
embedding-similarity precision.

We evaluate \psm{} as a retrieval substrate for egocentric look-back QA
(``where did I last see my bike?'', ``when was I last at this
intersection?''). At a bounded deployment point it recovers
21 of brute-force CLIP-cosine retrieval's 25 Hit@5 hits ($84\%$; single
session/seed, corroborated by a seed-averaged 30-session sweep) with
session-length-invariant per-cell state (sub-2\,ms/query, ${\sim}20$\,MiB on a
Galaxy S22), and matches it exactly once
reservoir eviction is removed---a substrate-correctness check
(\S\ref{sec:results-main}). The result generalizes across \textbf{14
street-scale sessions, 3 sensor stacks, and 3 encoder
families}~\cite{dai2023sloper4d,pan2025lookout,tschannen2025siglip2} (11/14 for
the strongest single encoder, 13/14 under an any-encoder disjunction;
\S\ref{sec:results-multi-corpus}), and \psm{}'s query-matched retrieval
supplies the spatial-temporal prefilter uniform-sampling MLLMs lack---on two
sessions even the any-of-$K$ coverage of $K{=}8$ uniform frames scores Hit@5 $=0\%$ (\S\ref{sec:results-vanilla-mllm}).
On 102.9\,h of metropolitan driving (Honda HDD~\cite{ramanishka2018hdd})
\psm{} exercises its target multi-session regime: sublinear state
($1.3$--$7.2\times$ below a dense bank), cross-session cardinality accruing
across 219 days in a $1\,\mathrm{KiB}$ sketch, and label-free place
retrieval (0.853 AUC vs.\ a 0.498 null; \S\ref{sec:results-hdd}). The C
engine ($\sim$700 LoC) and harness are released under MIT.

\keywords{Spatial memory \and Bounded memory \and Dynamic spatial

\end{abstract}
