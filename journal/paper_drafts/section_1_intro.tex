\section{Introduction}
\label{sec:intro}

For an intelligent agent to hold persistent memory of its environment, its internal state cannot grow unboundedly with time. Standard retrieval-augmented systems embed every observation into a dense vector bank that grows linearly with recording duration, making continuous multi-session memory prohibitively expensive on-device. Long-context modeling of the models themselves~\cite{arora2024linear,chen2024vljepa} does not address the systems bottleneck: how to structure a dynamic spatial representation supporting test-time memory updating without unbounded state explosion?

\paragraph{The memory-centric systems question.}
Three properties define a viable retrieval substrate for multi-session persistent memory: \emph{memory-budgeted systems}---state must be bounded independently of sequence length, scaling instead by physical area explored; \emph{dynamic spatial representation}---the index must natively support test-time memory evolution, allowing old information to decay while maintaining unique-event cardinality across revisits; and \emph{streaming ingestion}---observations must update the memory in-place and online.

\paragraph{Probabilistic Spatial Memory.}
We propose \textbf{\psm{}}, a streaming spatial-temporal index for
egocentric look-back retrieval built on three data structures over an H3
hex-grid tessellation: (1)~\emph{reservoir-sampled exemplars} per cell
retain a fixed-size embedding sample; (2)~a \emph{time-decayed ring
buffer of HyperLogLog sketches} per cell tracks unique-event cardinality
over recent windows; (3)~a \emph{per-cell capacity bound}
(\caponek{}) limits how many top-$K$ slots one cell may fill---enforcing
strict spatial diversity at $\texttt{cap}{=}1$ and recovering
unconstrained top-$K$ at $\texttt{cap}{=}K$. Memory is bounded per cell,
ingestion is streaming, and top-$K$ search returns $K$ candidate
$(t,\mathrm{lat},\mathrm{lng})$ triples in sub-millisecond host-CPU
wall-time on both a synthetic stress test and the measured Nymeria
\psm{} state (\S\ref{sec:limitations} scopes the missing on-device
measurement).

\paragraph{Evaluating the retrieval substrate.}
To demonstrate that \psm{} functions as a high-fidelity retrieval substrate, we evaluate it on the challenging task of egocentric look-back QA (e.g., ``where did I leave my keys?''). Multimodal LLMs (Gemini~3, Claude~4, GPT-4o) achieve strong single-frame grounding yet remain notoriously brittle on temporal grounding over long, continuous video sequences~\cite{cheng2024videgothink,chen2025groundedmultihop}. We compose \psm{} as an upstream spatial \emph{prefilter} to a frontier MLLM (\S\ref{sec:pipeline}). The two contributions are complementary: \psm{} guarantees bounded-memory recall, while the MLLM supplies downstream localization precision.

\paragraph{Contributions.}
\begin{itemize}
  \item \textbf{\psm{} architecture:} a bounded-memory streaming
    spatial-temporal index combining H3 cells, time-decayed HLL ring
    buffers, and reservoir-sampled exemplars
    (\S\ref{sec:method}).

  \item \textbf{\caponek{} knob + oracle sanity check:}
    at the bounded $R{=}128$ operating point, \texttt{cap}=$K$
    reaches 21/187 hits vs.\ brute-force CLIP's 25/187; at oracle
    reservoir size $R{=}1024$, it recovers the same 25/187 hits with identical
    mIoU, confirming the expected top-$K$ equivalence when reservoir
    eviction is removed. $\texttt{cap}{=}1$ paired with
    Gemini rerank achieves mIoU\,0.069,
    statistically indistinguishable from brute-force 0.074
    (bootstrap $\Delta{=}{-}0.005$, 95\,\% CI
    $[-0.032,{+}0.021]$) (\S\ref{sec:results-main}).

  \item \textbf{Generalization + the MLLM blind spot:}
    the spatial-axis result holds on 13/14 street-scale sessions across
    3 sensor stacks and 3 encoders (supp.\ Table~\ref{tab:multi-corpus-h3});
    and \psm{}'s query-guided retrieval supplies the
    spatial-temporal prefilter that uniform-sampling MLLMs lack---at
    matched $K{=}8$ it reaches every session vanilla Gemini misses,
    including 4 where uniform frames never land in a GT interval
    (\S\ref{sec:results-vanilla-mllm}).
    Open-source under MIT (\S\ref{sec:conclusion} footnote).

  \item \textbf{Multi-session persistence (Honda HDD):} on 102.9\,h of
    metropolitan driving with genuine revisits (47\% of traversal events over
    cells re-driven on $\geq2$ days, median 106-day gap), \psm{} demonstrates
    the multi-session regime its design targets: state that grows
    \emph{sublinearly} in observation count ($O(\text{area})$, not
    $O(\text{time})$; $1.3$--$7.2\times$ below a dense bank as ingest rate
    rises), a $1\,\mathrm{KiB}$ HLL sketch that accrues unique-event cardinality
    across 219 days while decaying between visits, and label-free cross-session
    place recognition (0.853 AUC vs.\ a 0.498 shuffled null)
    (\S\ref{sec:results-hdd}).
\end{itemize}
